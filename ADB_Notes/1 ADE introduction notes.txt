5.Azure Databricks(ADB):
    -It is a fast Apache-spark based data analytics platform for microsoft azure

  what is Databricks---->provides spark cluster in cloud
  what is spark?
  -It is a very high speed processing Execution model to process huge data
   with high speed.
   Spark features---->1)in-memory computation
                      2)Supports MPP(Massive parallel process)
   spark --->100 times faster than normal disk processing

   spark requires a cluster--->which was provided by Databricks

   Cluster: Group of nodes(CPUs) connected in a network
            There are 2 types of nodes
            1.Driver node(master node)
            2.worker nodes(slave node)
  It is a master-slave Architecture
  i.e single master and multiple slaves(workers)

  ex: assume we have 500nodes
      This 500nodes cluster is worthy processing 2TB of data at a time

     Tommorrow--->ur data volume increased
       if same cluster is used-->speed goes down--->as data volume increased
     so we need to scale up the cluster--->by adding new nodes(100 nodes added)
                                          after 2 months again 100 nodes added
     Everytime scaling up your physical data center is a complex task

     so that's why--->i need a cluster in cloud and that too
                      with auto-scaling capability

     who is providing this-------->Databricks

    Databricks--->provides spark cloud cluster with auto scaling feature

    ex:
       Today--->my dataloaad---->requires 100 nodes
       Tommorrow--->data volume increased-->it has to be extended to 200 automatically
   after processing is completed and again it has to revert back to 100nodes

  This is General Databricks
