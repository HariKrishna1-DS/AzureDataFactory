
Triggers:
--------
-Triggers for automatic execution of pipelines
     -scheduled-based
      event-based

Types of triggers:

1.Schedule trigger

2.Tumbling window trigger

3)Event Based Trigger
    -storage Event Trigger
    -custom Event Trigger
4)manual trigger

-------------------------------
1)Schedule trigger:
   -Executes pipeline on a specified schedule
    i.e hourly,daily,weekly,monthly
    ex: here we can set the start and end dates
         30th of each month
         1st of each month
   Schedule trigger are built with " many to many" relationship
   -one data pipeline can be run by multiple schedule triggers
    one schedule trigger can run several Data pipelines

------------------------------------------------------------------------------

2)Tumbling Window:
    Executing pipeline at a specified time interval
    mostly usefull for copying or migrating historical data
    ex: Copying data from database to Datalake regularly
         you want to keep it in seperate files or folders for every hour/day

   -To implement this, you have to set a tumbling window trigger for 
    every 1 hour(or) every 24 hrs

  -The tumbling window trigger sends the start and end times for 
   each time window to the database and also returns all the data
   b/w those periods
  -Finally the data for each hour or day can be saved in its own file or folder

  -here we can provide the past date and time
------------------------------------------------------------------------------

3)Event Trigger: Executes a pipeline in response to events such as
                i)data loading/arriving in the storage account
               ii)file being added or modified
              iii)file being deleted

 Event Trigger: 2 types
    1)Storage Event Trigger
    2)Custom Event trigger

4)manual trigger:Allows manual execution of a pipeline by a user
                 Add trigger--->trigger now
