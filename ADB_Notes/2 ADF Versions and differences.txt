

ADF Versions and differences:
-----------------------------
2 versions

1.ADF Version1 --->Not supported now
2.ADF Version2

ADF Version1 : It is used to perform EL Only,but not ETL
                there were no transformations
                No built-in Transformation facilities
 -To perform Transformations,some additional services required such as

1.ADLA (Azure Datalake Analytics)
       -It is available only for ADLS Gen1
                                 (Azure Data LAke Storage)
      ADLS has 2 versions---->Gen1 and Gen2
                              only for Gen1--->ADLA is available

      within this GEn1----->Analytics are done by USQL
      USQL--->Unified Structured Query LAnguage
              It is not equivalent to basic sql
              USQL is totally different
-----------------------------------------------------------------------------
2. HDInsights service------>(Hadoop Insights)
        Hadoop is a distributed computing cluster
        Same BigData Hadoop Framework in Azure cloud is called as HDInsights

       -Here we have a DAtaflow language called APACHE PIG
        Dataflow means sequence collection of pipes
        -At each pipe diff transformations will happen

       At pipe1----->Data Extraction
       At pipe2----->Data Cleaning
       At pipe3----->Creating new fields
       At pipe4----->filtering
       At pipe5----->Aggregations
       At pipe6----->writing output to Target

  Using Pig, these dataflows are written and Transformations are performed

------------------------------------------------------------------------------

      -we need to write Azure Functions
       These Azure Functions are complex to implement

4)Azure Databricks

5)Stored Procedures
