
Parameterization dataset
------------------------
Dynmicaly passing values during run time to avoid duplicate task


ex:  azsqldb(table1)
           dataset   ------>copy data ------------->Datalake
         tablename->table1                          dataset
                                                     target(container)

another Task(Task2)
    azsqldb(table2)
           dataset   ------>copy data ------------->Datalake
         tablename->table2                           dataset
                                                     target(container)

another Task(Task3)
    azsqldb(table3)
           dataset   ------>copy data ------------->Datalake
         tablename->table3                          dataset
                                                     target(container)

here 3 tasks, instead of duplicating the tasks, with a single pipeleine
i need to copy the tables(table1,table2,table3) into target(datalake)

===============================================================================
table1
table2
table3------------>Copy data----------->Datalake
  .
  .
table20

If i have 20 tables and i want to copy that into datalake 

here you need to create 20pipelines and pass diff tablenames to dataset

To avoid this, we have parameterization
-here we create single dataset--->for azsqltable
                                  pass tablename as table1 during runtime
              for copying table2-->we pass tablename as table2 during runtime
              that is how we use only one dataset
==============================================================================
