---------------------------------
-Conditional split transformation routes or diverts data row to diff targets

-Conditional split splits data based on single condition or multiple conditions

-Previously, distribution happened based on files
       here,distribution based on data

 source1---->Conditionalsplit
             settings
             split on -->1)first matching condition

                          -data is split on the first matching condition 
                           just like elif


                         2)all matching conditions
                           -data is split on all the matching conditions
                        sal>20k------>sink1
                        sal>40k------>sink2
                        sal>60k------->sink3
                        default------->sink4
                       if sal is 10k------->which sink--->default
                                 20k------->   "    "        "
                     ex:Ravi sal is 70k--->he falls in which sink-->
                                            Ravi is in all the 3 sinks
                 -------------------------------------------------------------       
                   in 1st matching condition--->if 1st condition is True
                                                it wont check with 2nd condition
                here if 2st condition is false, it checks with 2nd condition  
                                          if True,it wont check 3rd condition
               if all conditions are false then it will go with default


          split condition:
                   stream name      condition
                +  lg               equals(pname, 'LG')---->save and finish
                +  samsung          equals(pname,'Samsung')  "
                +  Sony             equals(pname,'Sony') 
                   existing         Rows that do not meet any condition will
                                    use this output stream
