
Tumbling window Trigger:
-----------------------
-Used to schedule the execution of pipeline based on predefined time
 intervals known as tumbling windows

diff b/w Schedule trigger and tumbling window

Schedule trigger--->we can run with present date and future date

tumbling window---->we can run with historical date(previous date)


tumbling windows are fixed size,non overlapping time intervals

-The trigger fires at the start off each tumbling window,initiating the
 execution of the associated pipeline

ex:
  You want to run the pipeline from 1st July to 6th July i.e for every 24 hours/day
  and create a csv file in the storage account

  Now it will divide your execution into window

 1st Jul--->2nd Jul----->1st window -->1 pipeline runs--->1 csv to be created
 2nd Jul--->3rd Jul----->2nd window -->1 pipeline runs--->1 csv to be created
 3rd Jul--->4th Jul----->3rd window -->1 pipeline runs--->1 csv to be created
 4th Jul--->5th Jul----->4th window -->1 pipeline runs--->1 csv to be created
 5th Jul--->6th Jul----->5th window -->1 pipeline runs--->1 csv to be created

so here the pipeline runs for 5times
here we have given 24hr as the interval

so it will divide ur run into windows that's why we call tumbling window trigger
