
select Transformation:
----------------------

select Transformation performs the following
1)renaming the source cols as per target
2)Dropping the source cols 
3)re-odering the source cols as per the target

if target table has diff no of cols
if source table has diff no of cols

if automapping is enabled , the data loading will be failed into 
associated cols

ex: source--->id,name
    sink----->eid,ename
    rename source cols----->to eid and ename as per target

2)drop the columns
  
  whenever some data is trying to get loaded into target

  ur adf dataflows are trying to push all the data into target table
  but target table is not having all the cols

ex: source-->eid,ename,sal
    sink--->eid,ename
    at the time of loading drop the col---<>sal
    here eid--->eid
         ename-->ename mapping will happen

3)re-ordering the cols
   source--->eid,ename,dno,sal,gend
   sink----->eid,ename,sal,gend,dno

here we need to re-order the cols of source--->as per target

ex:To merge 2 datasets
   union of source1,source2------->into target(sink)

   source1--->eid,ename
   source2--->ename,eid

 you need to re-order any one source and then perform union:

Limitations of Select T/R: you cannot generate new columns or fields

To generate new columns or fields,we have another Transformation called
"derived column"transformation

drop--->if 30 cols in source and we want only 20cols in target-->drop the remianing cols
