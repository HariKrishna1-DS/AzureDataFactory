
PowerQuery if ADF:
-----------------
The Power Query activity allows to build and to execute data wrangling in
data factory pipeline

Data wrangling is a process of cleaning ,structuring and transforming raw data
into usable format for analysis
we also call as DAta munging,data blending or Data scrubbing

PowerQuery in ADF is translated into spark and run on on-demand spark clusters
so it is more scalable
Power Query of ADF wont support all the features as PowerBI
