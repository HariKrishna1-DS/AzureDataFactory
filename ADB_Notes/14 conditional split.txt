filters:
2 additional filters am going to add
                                    |------>Filter1(starts with 'adf')
   search :filter       Get Metadata
                                    |------>Filter2(not starting with 'adf')

   click filter1
         settings:
       items(inpuildit)->add dynamic content-->select-->GetMetadata1 childItems
                        @activity('Get Metadata1').output.childItems

       condition : add dynamic content--->Functions-->startswith
                     @startswith(item().name,'adf')
       ok
 
  click filter2
         settings:
       items(inpuildit)->add dynamic content-->select-->GetMetadata1 childItems
                        @activity('Get Metadata1').output.childItems

       condition : add dynamic content--->Functions->logical functions
                     @not()
                     @startswith(item().name,'adf')
                     merge both
                     @not(startswith(item().name,'adf')
      ok
     validate
     debug
      filter1 o/p--->3 files
      filter2 o/p--->4 files
      filter1 and filter2 are parallely executed, as there is no dependency

foreach

       for 2 filters--->2 foreach activity

       search :foreach   

                                    |------>Filter1----->foreach1(copy data1)
   search :filter       Get Metadata
                                    |------>Filter2----->foreach2(copy data2)

  click foreach1(atleast one subactivity in it-->copyActivity)

        settings:
             sequential   True
             Items(Input) :add dynamic content--->Filter1 activity o/p
                            @activity('Filter1').output.Value
             Activities
                         Foreach       edit-->click
                         search :copydata
                         source: ds_mystoragelake5001_source
                                 takes filter o/p files only so
                                 select-->wild card folder path
                    source-->add dynamic content--->foreach1 current item
                             @item().name
                    sink: ds_mystoragelake502_containerx
