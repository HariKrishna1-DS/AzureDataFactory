
Derived column Transformation:
-----------------------------
It performs the following
i)Generates New column from the existing column
ii)updating a column

==============================================================================
Task 1: Generate New fields--->tax,hra,netsal

source-->emp--->eid,ename,sal,gend,dno ---->here only 5 cols

I want load into target--->but target has more cols

sink--->empres--->eid,ename,sal,gend,dno,tax,hra,netsal

tax-->10% of sal as tax
hra-->20% of sal
netsal=sal+hra-tax
==============================================================================
Derived and select
------------------
in select i want to perform the following
1)rename--->eid to empcode
2)drop--->gend
3)reorder this-->empcode,ename,sal,dno,tax,hra,netsal
            to-->ename,empcode,sal,tax,hra,netsal,dno

At runtime, while loading data only to perform these Transformations
or generate these cols --->we use derived column Tranaformation

Dataflow:

source1--->derived column T/R----->select---------------->sink1
           I will generate        -here whatever fields not required i will drop
           new fields             -any field with diff name, i will rename
                                  -any re-order as per sink-->I will re-order
==============================================================================
process flow
  source1--->derived column------------>select---------------->sink1
             Generate new fields       1)renme eid to empcode
             tax-->10% of sal as tax   2)drop gend column
             hra-->20% of sal          3)re-order the cols
             netsal=sal+hra-tax         ename,empcode,sal,tax,hra,netsal,dno

------------------------------------------------------------------------------
linked services already available
datasets already avialable

===============================================================================
dataflow--->newdataflow-->dataflow_derived_select

add source--->source1
              ds_mystoragaelake_source_emp
              projection--->make eid,sal,dno to integers
          source1------>derived column
                        settings
                        Add+--->new column
                                tax    : sal*0.10 --->save and finish
                                hra    : sal*0.20       "
                                netsal :sal + (sal * 0.20) - (sal*0.10)
                                        here we cannot say-->sal+hra-tax
                                        bcoz still they are not generated
                                        they will be committed only when
                                        the T/R executes
                         
  
   derived column--->select
                     settings

                     1)Rename--->eid--->empcode
                     2)select-->gend--->delete
                     3)re-order the cols->ename,empcode,sal,tax,hra,netsal,dno


           source1--->derived column--->select----->sink1

           sink1 settings
           ds_mystoragelake_target
